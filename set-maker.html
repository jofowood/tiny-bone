DYO - Tiny Bone Set

Seventeen Tiny Bone, each used once, in any arrangement on a 2×17 board. Your shape can be any width up to 17 and 1 or 2 rows tall. Whatever outline you build has to end up a solid rectangle, four square corners, no notches or holes. Use the solid colors to cover any gap inside your set that doesn't include a Tiny Bone.

Each Tiny Bone Set is made to order of individual original tin type Tiny Bone images. Generally, the backing block the set is built on will be wood. However, the final backing material used is at the artist's discretion. If your set includes color, those spaces will be hand painted acrylic on the backing.

Each Tiny Bone Set is unique and handmade. Pricing is quoted once your set is requested. Currently I'm estimating $45-$55/image. Production timelines vary.

The images on this webpage are meant as a design tool only. Your Tiny Bone Set will be unique.
